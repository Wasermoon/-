# Практикалық тапсырма №1 — IT Quiz

HTML, CSS және JavaScript көмегімен жасалған интерактивті онлайн тест.

## Іске қосу
1. Осы папкадағы `index.html` файлын браузерде ашыңыз.
2. Әр сұраққа бір жауап таңдаңыз.
3. «Келесі сұрақ» батырмасын басып жалғастырыңыз.
4. Соңында нәтиже көрсетіледі. «Қайта өту» батырмасы тестті қайта бастайды.

## Файлдар
- `index.html` — бет құрылымы
- `style.css` — дизайн
- `script.js` — сұрақтар, жауаптарды тексеру және ұпай есептеу
