# КІРІСПЕ

Қазіргі таңда веб-сайттар адамдардың күнделікті өмірінде маңызды рөл атқарады. Веб-сайтты қолданушыларға ыңғайлы әрі қызықты ету үшін интерактивті элементтер қолданылады. Интерактивті элементтер пайдаланушы мен веб-сайт арасындағы байланысты жақсартып, сайттың функционалдығын арттырады.

Бұл практикалық жұмыстың мақсаты – HTML, CSS және JavaScript бағдарламалау тілдерін пайдалана отырып, веб-сайтқа интерактивті элемент жасау, оны безендіру және браузерде дұрыс жұмыс істеуін қамтамасыз ету.

Жұмыс барысында веб-беттің құрылымы жасалып, CSS көмегімен дизайны безендіріледі. Ал JavaScript арқылы батырмалар мен басқа да интерактивті элементтердің әрекеттері іске асырылады.

Практикалық жұмыстың нәтижесінде веб-сайт құру, оны безендіру, интерактивті функцияларды қосу және дайын жобаны GitHub платформасына жүктеу дағдылары қалыптасады.
